ƒx Understand Expense (Formula Engine)

Discovery Engine APIs return live resource inventories (agents, data stores, connectors, licenses) and activity logs rather than billing invoices. All $ Expense and $ Value Saved metrics are calculated deterministically from live API counts using the formula below:

1. Variable Session & Token Spend: Sessions × Turns × ((InTokens × InPrice + OutTokens × OutPrice)/1M + InvocationFee) × ArchIntensity
2. Infrastructure & Seat Spend: (ActiveConnectors × ConnectorMonthlyCost) + (AssignedLicenses × LicenseMonthlyCost)
3. Productivity Value Saved: (Sessions × AvgMinutesSaved / 60) × HourlyRate
